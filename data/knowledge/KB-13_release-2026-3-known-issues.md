# Release 2026.3 known issues

## Report filters reset
In release 2026.3, saved filters on the Asset Register report may reset after export. Workaround: save the filter as a named view before exporting. A fix is planned for 2026.4.

## Slow lease rollforward
The Lease Rollforward report can take several minutes for more than 5,000 leases. Workaround: run it by legal entity.
